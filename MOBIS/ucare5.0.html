5. 빌드할 때 지킬 것

  • Gradle 은 JDK 17 이상(권장 JDK 21)에서 돌린다. JAVA_HOME을 JDK 21 로 두거나 명령행에 -Dorg.gradle.java.home=<JDK 21 경로>를 준다. JDK 11 로 돌리면 「Dependency requires at least JVM runtime version 17」로 멈춘다.
  • 외장 Tomcat 용 ROOT.war 는 war 태스크로 프로필(local·dev·prd)마다 따로 만든다. clean은 따로 먼저 실행한다.
  • 출력 위치는 build.gradle 그대로다: Windows 는 D:\UCARE_PROJECT_4.2_64bit, 그 밖의 OS 는 build/libs. 다른 폴더로 받으려면 각자 Gradle init 스크립트로 출력 폴더를 바꾼다(build.gradle은 고치지 않는다).
  • 소스가 바뀌면 이전 WAR 는 낡은 것이다. 넘기기 전에 다시 빌드한다.
gradlew.bat clean "-Dorg.gradle.java.home=<JDK21 경로>" --no-daemon
gradlew.bat war -Pprofile=<local|dev|prd> "-Dorg.gradle.java.home=<JDK21 경로>" --no-daemon

JAVA_HOME이 JDK 21 이면 -Dorg.gradle.java.home은 빼도 된다.

잔재 (정리 후보)쓰는 곳 없이 남은 jaxb-api·javax.activation-api, SAP jar 를 지웠는데도 남은 로컬 SAP 설정·주석, 지운 DB 드라이버(ojdbc8·mariadb·tibero6) 복구용 주석·설정, 인터페이스 관리 화면의 데모 행(가리키는 샘플 주소는 삭제됨), Tiles 주석, Docker/compose 파일(운영 미사용)

7. 용어 풀이

용어한 줄 풀이
LTS오래 지원하는 Java 판(11·17·21). 이번 작업의 출발 이유
javax / jakarta서블릿·메일 같은 Java EE 표준의 패키지 이름. 관리 주체가 바뀌면서 javax.*가 jakarta.*로 바뀌었다. Tomcat 10 이상과 Spring 6 은 jakarta 만 받는다
Jakarta EE 10 / Servlet 6.0jakarta 이름을 쓰는 표준 판. Tomcat 10.1 이 이것을 구현한다
외장 Tomcat / 내장 Tomcat외장: 서버에 따로 설치한 Tomcat 에 WAR 를 올리는 방식(운영). 내장: 앱 안에 Tomcat 을 넣어 bootRun·java -jar로 띄우는 방식(개발용)
WAR / ROOT.war / bootWarWAR: 웹 앱 묶음 파일. ROOT.war: 외장 Tomcat 의 루트(/)에 올리는 파일. bootWar: 내장 Tomcat 으로도 실행되는 WAR(운영 미사용)
바이트코드 목표(release)컴파일된 클래스가 요구하는 최소 Java 판. 17 로 두면 JDK 17·21 모두에서 돈다
Spring Boot / BOMBoot: Spring 앱을 쉽게 띄우는 틀. BOM: 의존 라이브러리 판을 한 번에 정한 목록. 보안 판이 필요하면 일부 판만 덮어쓴다
eGovFrame RTE전자정부 표준프레임워크 실행환경. 이 프로젝트의 필수 기반
코어 jar사내 공통 기능을 담은 ucare-app-core 라이브러리. 앱이 jakarta 로 바뀌어 코어도 다시 빌드했다
TilesJSP 화면 틀을 조립하던 라이브러리. Spring 6 에서 지원이 끊겨 jsp:include로 바꿨다
multipart / 리졸버파일 업로드 요청 형식과, 그것을 해석하는 Spring 부품
Connector (maxPartCount 등)Tomcat 이 HTTP 요청을 받는 입구 설정. 업로드 파트 수·헤더 크기·본문 크기 한도를 여기서 정한다
setenv외장 Tomcat 이 기동할 때 읽는 JVM 옵션 파일(setenv.sh)
WebSocket / STOMP / Origin실시간 알림·채팅 통로 / 그 위 메시지 규약 / 요청이 온 사이트 주소. Origin 을 제한해 다른 사이트의 접속을 막는다
SameSite=Lax다른 사이트에서 보낸 POST 에 세션 쿠키가 붙지 않게 하는 쿠키 속성
CVE / OSS 지원 종료공개된 보안 취약점 번호 / 무료 패치가 더 나오지 않는 판
XSS웹 화면에 스크립트를 심는 공격
Gradle wrapper저장소에 함께 넣은 Gradle 실행기(gradlew). 정해진 Gradle 판을 받아 쓴다
회귀예전에 되던 것이 바뀐 뒤 안 되는 것. 원본에서도 안 되던 것은 회귀가 아니다
