JDK21 업그레이드판 로컬 개발 환경 설치 안내

작성일: 2026-10-12 · 대상: uCare MOBIS 앱 JDK 21 업그레이드판을 자기 PC 에서 빌드·실행할 개발자 (Windows 기준)

1. 개요

uCare MOBIS 앱을 JDK 11 · Spring Boot 2.7 · Tomcat 9 에서 JDK 21 · Spring Boot 3.5.6 · Spring 6.2.19 · eGovFrame 5.0.2 · Jakarta EE 10 · Tomcat 10.1.60 으로 올린 판입니다. 이 문서는 저장소를 받아 자기 PC 에서 빌드하고 띄우기까지의 절차입니다.

항목판
JDK (실행·빌드)21 (Temurin, 검증한 판 21.0.12.1+1). 컴파일 결과는 Java 17 바이트코드
Gradle8.14.5 — 저장소의 gradlew 가 자동으로 받음(따로 설치 안 함)
Spring Boot / Spring3.5.6 / 6.2.19
eGovFrame5.0.2
Tomcat10.1.60 (내장·외장 모두)

2. 저장소

구분주소설명

4. 담당자에게 받을 것

무엇왜
GitLab 어플 저장소 읽기 권한clone
내 PC 용 uCare 라이선스 파일 ucareLicense.dat앱이 기동할 때 PC 의 IP 와 만료일을 검사해, 맞지 않으면 기동을 멈춥니다. 저장소에 들어 있는 파일은 다른 PC 용이라 그대로는 기동이 거부됩니다. 내 PC IP 로 발급받아야 합니다(VPN 을 쓰면 기준 IP 를 담당자와 정합니다)
사내망 자리 또는 VPN앱이 기동하면서 바로 개발 DB(MSSQL)에 접속합니다. DB 에 닿지 않으면 기동이 실패합니다
화면 로그인 계정개발 DB 에 등록된 계정. 기동에는 필요 없고 화면을 쓸 때 필요합니다(로컬 설정은 OTP 꺼짐)
(사내 프록시가 있으면) 프록시 주소첫 빌드 때 인터넷에서 Gradle·라이브러리를 받습니다(9절)

5. 설치·실행 절차 (내장 Tomcat)

5-1. JDK 21 설치와 JAVA_HOME

JDK 21 을 설치한 뒤 시스템 환경 변수 JAVA_HOME 을 JDK 21 폴더로 둡니다. 아래는 설치 폴더가 C:\Java\jdk-21.0.12.1+1 인 예입니다(명령 프롬프트, 새 창에서 적용).

setx JAVA_HOME "C:\Java\jdk-21.0.12.1+1"

REM 새 명령 프롬프트를 열고 확인
"%JAVA_HOME%\bin\java" -version

다른 프로젝트 때문에 JAVA_HOME 을 JDK 11 로 두어야 한다면, 바꾸지 말고 Gradle 명령마다 "-Dorg.gradle.java.home=C:\Java\jdk-21.0.12.1+1" 을 붙여도 됩니다.

5-2. 소스 받기

git clone https://gitlab.nexfron.com:16060/hyundai-mobis/ucare-mobis-app-5.0.git
cd ucare-mobis-app-5.0

5-3. 라이선스 파일 넣기

담당자에게 받은 내 PC 용 파일로 덮어쓴 뒤, 이 파일이 커밋되지 않도록 표시합니다.

copy /Y <받은 파일 경로>\ucareLicense.dat src\main\resources\config\ucareLicense.dat
git update-index --skip-worktree src/main/resources/config/ucareLicense.dat

5-4. 로그·업로드 폴더

로컬 설정은 로그와 업로드 파일을 D:\UCARE_PROJECT_4.2_64bit\ucareFile\ 아래에 씁니다. D: 드라이브가 있으면 폴더를 만들어 둡니다(하위 폴더는 앱이 만듭니다). D: 드라이브가 없으면 9절의 「D: 드라이브가 없을 때」를 봅니다.

mkdir D:\UCARE_PROJECT_4.2_64bit\ucareFile

5-5. 빌드 확인

처음 실행하면 Gradle 8.14.5 와 라이브러리(수백 MB)를 내려받습니다. 두 번째부터는 받아 둔 것을 씁니다.

gradlew.bat compileJava

BUILD SUCCESSFUL 이 나오면 됩니다.

5-6. 실행 (bootRun)

gradlew.bat bootRun --args="--spring.profiles.active=local --ucareif.sap.enabled=false"
  • 로그에 Started UcareBootApplication 이 나오면 브라우저로 https://localhost:8080 을 엽니다. 자체 서명 인증서라 경고가 한 번 뜨는데 「계속」을 누르면 됩니다(http 로 열면 400).
  • --spring.profiles.active=local 은 꼭 줍니다. 빠지면 설정 값을 찾지 못해 기동이 실패합니다.
  • --ucareif.sap.enabled=false 는 SAP 연동 라이브러리가 없어서 끄는 것입니다(SAP 호출 화면만 동작하지 않음).
  • 끌 때는 Ctrl+C.

5-7. IDE 에서 실행할 때

  • 저장소 폴더를 Gradle 프로젝트로 가져옵니다(IDE 설정 파일은 저장소에 없습니다).
  • Lombok: IntelliJ 는 Lombok 플러그인과 Settings → Build → Compiler → Annotation Processors 의 「Enable annotation processing」을 켭니다. Eclipse/STS 는 lombok.jar 를 설치합니다.
  • 가장 간단한 방법은 IDE 의 Gradle 창에서 bootRun 을 실행하는 것입니다(위 인자를 실행 설정의 Arguments 에 넣음).
  • Application 으로 직접 실행하려면:
    • Main class: com.nexfron.core.UcareBootApplication
    • VM options: -Djava.net.preferIPv4Stack=true -Dspring.profiles.active=local -Ducareif.sap.enabled=false
    • Working directory: 저장소 최상위 폴더
    • IntelliJ 는 「Add dependencies with "provided" scope to classpath」를 켭니다(내장 Tomcat·JSP 엔진이 provided 범위)

6. 포트를 8080 에서 바꿀 때

포트를 바꾸면 자기 자신을 가리키는 주소 설정도 같은 포트로 맞춰야 합니다. 맞추지 않으면 첨부가 있는 글 삭제 등이 실패합니다. 예: 9090 으로 띄울 때 bootRun 인자에 더합니다.

--server.port=9090 --core.config.sys.url-code-reload=https://localhost:9090 --core.config.prj.kms-server-url=https://localhost:9090 --core.config.prj.url-com-cntnts=https://localhost:9090/kms/com/comCntntsDetail/

7. (선택) 외장 Tomcat 10.1.60 에서 ROOT.war 확인

운영은 외장 Tomcat 10.1.60 에 ROOT.war 를 올리는 방식입니다. 같은 방식으로 확인하고 싶을 때만 합니다. Tomcat 9 는 jakarta 를 지원하지 않아 쓸 수 없습니다.

7-1. ROOT.war 만들기

gradlew.bat clean
gradlew.bat war -Pprofile=local

Windows 에서는 결과가 D:\UCARE_PROJECT_4.2_64bit\ROOT.war 로 나옵니다. 프로필(local·dev·prd)을 바꿔 빌드할 때는 매번 clean 을 먼저 합니다. 앞 프로필의 라이선스·에디터 파일이 build 폴더에 남아 섞일 수 있습니다.

7-2. Tomcat 준비

  1. zip 을 원하는 곳에 풉니다(예: C:\Tomcat\apache-tomcat-10.1.60).
  2. webapps\ROOT 폴더(기본 첫 화면)를 지우고, 7-1 의 ROOT.war 를 webapps\ 에 복사합니다.
  3. https 용 자체 서명 키를 만듭니다(비밀번호는 아무 값이나 정해서 아래 server.xml 에도 같은 값을 넣습니다). 
    "%JAVA_HOME%\bin\keytool" -genkeypair -noprompt -alias tomcat -keyalg RSA -keysize 2048 -validity 3650 -dname "CN=localhost" -ext "SAN=dns:localhost,ip:127.0.0.1" -storetype PKCS12 -keystore conf\localhost.p12 -storepass <비밀번호> -keypass <비밀번호>

7-3. conf\server.xml — Connector

기본 8080 Connector 를 아래로 바꿉니다. 업로드 한도 세 값(maxPartCount·maxPartHeaderSize·maxPostSize)은 꼭 넣습니다. 빠지면 Tomcat 기본값(파트 50개·파트 헤더 512바이트)이 걸려 첨부가 많은 저장, 긴 한글 파일명, 큰 편집기 본문이 「시스템 오류」로 거부됩니다.

<Connector port="8080" protocol="org.apache.coyote.http11.Http11NioProtocol"
           SSLEnabled="true" scheme="https" secure="true"
           connectionTimeout="20000" URIEncoding="UTF-8"
           maxPostSize="20971520" maxSwallowSize="20971520"
           maxPartCount="500" maxPartHeaderSize="2048">
  <SSLHostConfig>
    <Certificate certificateKeystoreFile="conf/localhost.p12"
                 certificateKeystorePassword="<비밀번호>"
                 certificateKeystoreType="PKCS12" type="RSA" />
  </SSLHostConfig>
</Connector>

7-4. conf\context.xml — 세션 쿠키

<Context> 에 useHttpOnly="true" 를 주고, 안에 다음 세 줄을 넣습니다(외장 Tomcat 은 Spring 의 쿠키 설정을 쓰지 않으므로 여기서 같은 값을 줍니다).

<Context useHttpOnly="true">
  ... (기존 내용) ...
  <Manager pathname="" />
  <CookieProcessor className="org.apache.tomcat.util.http.Rfc6265CookieProcessor" sameSiteCookies="lax" />
  <JarScanner scanClassPath="false" />
</Context>

7-5. bin\setenv.bat (새로 만듦)

set "JAVA_HOME=C:\Java\jdk-21.0.12.1+1"
set "CATALINA_OPTS=-Dspring.profiles.active=local -Ducareif.sap.enabled=false -Djava.net.preferIPv4Stack=true -Dfile.encoding=UTF-8"

7-6. 실행

cd C:\Tomcat\apache-tomcat-10.1.60
bin\catalina.bat run

WAR 를 펼친 뒤 https://localhost:8080 을 엽니다. 내장 Tomcat(5-6)과 같은 포트라 둘을 동시에 띄우지 않습니다.

9. 문제가 생기면

증상원인과 해결
Dependency requires at least JVM runtime version 17. This build uses a Java 11 JVM.Gradle 이 JDK 11 로 돌고 있습니다. JAVA_HOME 을 JDK 21 로 바꾸거나 명령에 "-Dorg.gradle.java.home=<JDK 21 경로>" 를 붙입니다
Java home supplied is invalid (D:/UCARE_PROJECT_5.0_64bit/... 경로가 보임)예전 커밋을 받았습니다. 최신 main 으로 git pull 하거나, 명령에 "-Dorg.gradle.java.home=<JDK 21 경로>" 를 붙입니다
기동 로그에 UCARE LICENSE FILE NOT EXIST OR INCORRECT LICENSE KEY / UCARE LICENSE IS NOT VALID / UCARE LICENSE EXPIRATION DATE HAS PASSED라이선스 파일이 없거나, 내 PC IP 용이 아니거나, 기간이 지났습니다. 담당자에게 내 PC IP 로 다시 받습니다. VPN 을 켜고 끄면 IP 가 바뀔 수 있습니다
기동 중 DB 연결 시간 초과 (HikariPool, SQLServerException)개발 DB 에 닿지 않습니다. 사내망·VPN 연결을 확인합니다
Could not resolve placeholder ...spring.profiles.active=local 이 빠졌습니다(5-6, 5-7)
D: 드라이브가 없을 때로그 경로는 src\main\resources\config\logback-spring-local.xml 안에 D:/UCARE_PROJECT_4.2_64bit/ucareFile/logs/... 로 적혀 있어 실행 인자로는 바뀌지 않습니다. 이 파일을 저장소 밖(예: C:\ucare\logback-local.xml)으로 복사해 FILE_DIR·BASE_CTI_DIR 두 값을 바꾼 뒤 실행 인자에 더합니다(원본 파일은 고치지 않음): 
--logging.config=file:C:/ucare/logback-local.xml --file.path.server-upload=C:/ucare/ucareFile
단, 첨부 이미지 표시 경로(/upload/**)는 코드에 D: 경로로 고정돼 있어, D: 없이는 업로드한 이미지 미리보기가 보이지 않습니다
첫 빌드에서 라이브러리 내려받기 실패 (특히 org.egovframe)인터넷이 막혀 있거나 프록시가 필요합니다. eGov 라이브러리는 maven.egovframe.go.kr 에서만 받을 수 있습니다. 프록시가 있으면 %USERPROFILE%\.gradle\gradle.properties 에 넣습니다: 
systemProp.http.proxyHost=<프록시 주소>
systemProp.http.proxyPort=<포트>
systemProp.https.proxyHost=<프록시 주소>
systemProp.https.proxyPort=<포트>
Port 8080 was already in use다른 프로그램(또는 다른 Tomcat)이 8080 을 쓰고 있습니다. 그것을 끄거나 6절처럼 포트를 바꿉니다
브라우저 「안전하지 않음」 경고로컬 자체 서명 인증서라 정상입니다. 「계속」을 누릅니다
서버를 끈 뒤 열어 둔 화면에 「서버와 통신 중 장애가 발생 하였습니다」가 1분마다 뜸우측 알림 확인이 1분마다 서버에 묻기 때문입니다. 서버가 꺼져 있으면 정상입니다. 탭을 닫습니다
편집기(Synap)에 「유효하지 않은 라이선스입니다」Synap 에디터 라이선스는 접속 호스트 이름 기준이라 localhost 에서는 이 안내가 뜰 수 있습니다(포트와 무관). 원본에서도 같은 동작이며, 운영은 운영 도메인용 라이선스를 씁니다
메인 화면 콘솔에 Stately is not defined원본에도 있던 동작입니다(부분녹취 스크립트). 화면 사용에는 영향이 없습니다
첨부 업로드·편집기 저장이 「시스템 오류」 (외장 Tomcat 에서만)server.xml Connector 에 업로드 한도 세 값이 빠졌습니다(7-3)
